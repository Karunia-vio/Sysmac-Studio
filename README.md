# SYSMAC STUDIO
Sysmac Studio adalah perangkat lunak terintegrasi yang dikembangkan oleh OMRON untuk merancang, mengkonfigurasi, dan memprogram sistem otomasi industri.

# Instalasi:
1. Unduh Sysmac Studio dari situs resmi Omron: https://www.omron-industrial.com/products/sysmac-studio
2. Ikuti petunjuk instalasi yang tersedia pada installer.
3. Hubungkan PLC Omron ke komputer menggunakan kabel Ethernet.
4. Luncurkan Sysmac Studio dan pilih perangkat yang akan dikonfigurasi.

# Cara Menggunakan:
1. Buka Sysmac Studio dan buat proyek baru.
2. Pilih jenis PLC dan perangkat keras yang digunakan.
3. Gunakan antarmuka grafis untuk mengonfigurasi perangkat I/O.
4. Tulis logika kontrol menggunakan Ladder Diagram (LD).
5. Unggah program ke PLC dan jalankan.
6. Gunakan fitur simulasi untuk menguji program tanpa perangkat keras.
